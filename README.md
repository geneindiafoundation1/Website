# GENE-INDIA Foundation

Website for [GENE-INDIA Foundation](https://geneindiafoundation.org) — Global Education and Networking for Excellence.

Built with Next.js. Content and logins are held off this repository.

## Local development

Node 22 or newer.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm start
npm run typecheck
```

Configuration lives in `.env.local` (copy from `.env.example`). That file is gitignored. Do not commit keys, passwords, or backups.
